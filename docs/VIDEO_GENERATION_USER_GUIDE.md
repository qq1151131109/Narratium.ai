# 场景视频生成功能 - 使用指南

## 📖 功能简介

场景视频生成功能可以根据角色对话内容自动生成场景视频。系统会：
1. 提取对话中的说话内容（高亮文本）
2. 使用 LLM 分析对话上下文并生成专业的图像和视频提示词
3. 调用本地 ComfyUI 工作流执行完整的视频生成流程：
   - **TTS（文本转语音）**：使用 Fish-Speech 生成角色语音
   - **文生图**：使用 FLUX 模型生成场景图片
   - **图生视频**：使用 WanVideo 将图片转换为动态视频
4. 在对话界面中播放生成的视频

**预计生成时间：30-90 秒**

---

## 🔧 前置要求

### 1. ComfyUI 环境

- ✅ 本地已安装 ComfyUI
- ✅ ComfyUI 在端口 9000 运行
- ✅ 已安装必需的模型和插件：
  - Fish-Speech TTS 模型
  - FLUX 文生图模型
  - WanVideo 图生视频模型
  - GIMM-VFI 插帧模型
- ✅ 工作流文件：`/docs/workflow/tts+文生图+图生视频-api-1101.json`

### 2. LLM 配置（用于提示词生成）

需要配置一个 LLM 服务用于生成图像和视频提示词：

**选项 A：OpenAI**
- API Key
- API 地址：`https://api.openai.com`
- 推荐模型：`gpt-3.5-turbo` 或 `gpt-4`

**选项 B：Ollama（本地）**
- 安装并运行 Ollama
- API 地址：`http://localhost:11434`
- 推荐模型：`llama2` 或其他支持的模型

### 3. 参考音频（可选）

为了获得更好的 TTS 效果，需要为每个角色准备参考音频：
- 格式：WAV
- 位置：`/home/ubuntu/shenglin/ComfyUI/input/角色名.WAV`
- 在工作流 JSON 中硬编码路径

## 📝 配置步骤

### 步骤 1：启动 ComfyUI

```bash
cd /home/ubuntu/shenglin/ComfyUI
python main.py --listen --port 9000
```

确认 ComfyUI 已成功启动并可访问 `http://localhost:9000`

### 步骤 2：打开设置面板

1. 在聊天界面，点击右上角的 **模型设置** 按钮（齿轮图标）
2. 滚动到底部，找到 **🎬 场景视频生成设置** 面板

### 步骤 3：启用功能

点击 **启用场景视频生成** 开关

### 步骤 4：配置 LLM（用于提示词生成）

这个配置与场景图片生成共享，如果已经配置过场景图片功能，可以跳过此步骤。

#### 使用 OpenAI：

1. **类型**：选择 `OpenAI`
2. **API 地址**：`https://api.openai.com`（或其他兼容的 API 地址）
3. **模型**：`gpt-3.5-turbo`（或 `gpt-4`）
4. **API Key**：输入你的 OpenAI API Key

#### 使用 Ollama：

1. **类型**：选择 `Ollama`
2. **API 地址**：`http://localhost:11434`
3. **模型**：`llama2`（或其他已安装的模型）
4. **API Key**：留空

### 步骤 5：保存设置

点击 **保存设置** 按钮

## 🎬 使用方法

### 生成视频

1. 在对话中找到包含说话内容的 **assistant 消息**
   - 说话内容需要用引号标注（`"` 或 `""`）
   - 例如：`"你好，今天天气真不错！"`

2. 在消息旁边找到 **视频生成按钮**（蓝色视频图标 🎥）
   - 位置：TTS 按钮之后

3. 点击按钮开始生成

### 生成过程

生成过程会显示实时进度：

```
正在分析对话... (0-5%)
  ↓
正在准备工作流... (5-10%)
  ↓
正在生成语音... (10-15%)
  ↓
正在生成图像... (15-40%)
  ↓
正在生成视频... (40-90%)
  ↓
正在优化帧率... (90-95%)
  ↓
正在合成最终视频... (95-100%)
  ↓
完成！
```

**预计总时间：30-90 秒**（取决于硬件配置）

### 观看视频

生成完成后，视频会自动显示在消息下方：
- 内置视频播放器，支持播放控制
- 可以下载视频文件（MP4 格式）

### 重新生成

如果对生成的视频不满意，可以再次点击按钮重新生成（每次生成都会有不同的效果）。

## ❓ 常见问题

### 1. 点击按钮后没有反应？

**检查清单：**
- ✅ 是否启用了场景视频生成功能？
- ✅ LLM API Key 是否正确配置？
- ✅ ComfyUI 是否在运行？（访问 `http://localhost:9000` 确认）
- ✅ 消息中是否包含说话内容（引号包裹的文本）？

**查看日志：**
打开浏览器开发者工具（F12）→ Console 标签，查看错误信息。

### 2. 显示"未找到说话内容"错误？

**原因：**消息中没有用引号标注的说话内容。

**解决：**确保消息包含类似这样的文本：
```
"你好！今天天气真好。"
```

或使用英文引号：
```
"Hello! Nice weather today."
```

### 3. 生成失败或超时？

**可能原因：**

1. **ComfyUI 未运行或端口不正确**
   - 检查：访问 `http://localhost:9000`
   - 解决：启动 ComfyUI 或检查端口配置

2. **ComfyUI 模型未加载**
   - 检查：ComfyUI 日志是否有模型加载错误
   - 解决：确保所有必需模型已安装并正确配置

3. **显存不足**
   - 检查：ComfyUI 日志是否有 CUDA OOM 错误
   - 解决：关闭其他占用显存的程序，或降低工作流参数

4. **LLM API 调用失败**
   - 检查：浏览器控制台是否有 LLM API 错误
   - 解决：验证 API Key 和网络连接

### 4. 视频质量不理想？

**优化建议：**

1. **提升对话质量**
   - 提供更丰富的场景描述
   - 包含角色动作、表情、环境等细节

2. **调整 LLM 模型**
   - 使用更强大的模型（如 GPT-4）以获得更好的提示词

3. **修改工作流参数**
   - 在 ComfyUI 中调整采样步数、CFG 等参数
   - 需要修改工作流 JSON 文件

4. **使用更好的参考音频**
   - 音质清晰、无背景噪音
   - 时长 5-10 秒
   - 包含目标角色的声音特征

### 5. 生成的视频无法播放？

**解决方法：**

1. 刷新页面重新尝试
2. 检查浏览器是否支持 H.264 视频格式
3. 下载视频文件，使用本地播放器观看
4. 检查 ComfyUI 输出目录权限

## 🎨 高级功能

### 自定义工作流

如果你想修改视频生成的效果（如分辨率、帧率、风格等），可以：

1. 在 ComfyUI 中打开工作流：`/docs/workflow/tts+文生图+图生视频-api-1101.json`
2. 修改节点参数：
   - 图像分辨率：节点 11 (Empty Latent Image) 的 width/height
   - 视频帧率：节点 50 (Video Combine) 的 frame_rate
   - 采样步数：节点 14 (Basic Scheduler) 的 steps
3. 保存工作流并重新加载应用

### 角色 LoRA 配置

工作流中可以为不同角色配置专属的 LoRA 模型：

1. 在 ComfyUI 中加载角色 LoRA
2. 修改工作流节点 10 (LoraLoaderModelOnly)：
   ```json
   "lora_name": "你的角色_LoRA.safetensors"
   ```
3. 保存工作流

### 参考音频管理

为每个角色准备专属的参考音频：

1. 准备角色音频文件（WAV 格式）
2. 放置到 ComfyUI input 目录：
   ```
   /home/ubuntu/shenglin/ComfyUI/input/角色名.WAV
   ```
3. 修改工作流节点 60 (FishSpeechTTS)：
   ```json
   "reference_audio_path": "/path/to/your/character/audio.WAV"
   ```

## 💡 使用技巧

### 1. 对话内容建议

为了获得更好的视频效果，对话内容应该：

✅ **包含丰富的场景描述**
```
"哇，这里的景色真美啊！看那边的夕阳，把天空都染成了金色。"
```

✅ **包含动作和表情**
```
"（微笑着走向窗边）今天的天气真好，我们出去散散步吧？"
```

❌ **避免过于简短**
```
"好。"
```

### 2. 最佳实践

1. **第一次使用**：先用简单的对话测试，确保流程正常
2. **参考音频**：为常用角色准备高质量的参考音频
3. **显存管理**：避免同时生成多个视频
4. **保存视频**：重要的视频及时下载保存

### 3. 性能优化

- **关闭不必要的功能**：如果不需要场景图片，可以关闭该功能节省资源
- **批量生成**：避免短时间内频繁生成，给 ComfyUI 足够的处理时间
- **监控资源**：使用 `nvidia-smi` 监控显存使用

## 🐛 故障排查

### 查看详细日志

**浏览器控制台：**
```
按 F12 → Console 标签
查找以 "=== Starting video generation ===" 开头的日志
```

**ComfyUI 日志：**
```bash
# 在 ComfyUI 运行的终端查看输出
# 或查看日志文件
tail -f /home/ubuntu/shenglin/ComfyUI/comfyui.log
```

### 常见错误代码

| 错误信息 | 原因 | 解决方法 |
|---------|------|----------|
| `Video generation is not properly configured` | LLM 配置缺失 | 检查设置面板中的 LLM API Key |
| `No speech content found` | 消息中没有说话内容 | 确保使用引号标注说话文本 |
| `Failed to submit workflow` | ComfyUI 未运行 | 启动 ComfyUI |
| `LLM API request failed` | LLM API 调用失败 | 检查 API Key 和网络连接 |
| `Polling timeout` | 生成超时（>5分钟） | 检查 ComfyUI 日志，可能是模型加载或显存问题 |
| `WebSocket connection failed` | 无法连接 ComfyUI | 检查 ComfyUI 是否运行在端口 9000 |
