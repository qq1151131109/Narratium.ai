# 角色卡定制方案 - 女优角色替换

## 📊 现状分析

当前系统有 **7个角色卡**，数据结构包括：
- `name`: 角色名称
- `description`: 详细描述（外貌、背景、职业等）
- `personality`: 性格特点
- `scenario`: 场景设定
- `first_mes`: 开场白

## 🎨 角色卡内容建议

### 必填字段

1. **name**: 中文名或艺名
2. **description**:
   - 基本资料（年龄、身高、三围）
   - 外貌特征
   - 职业背景
   - 性格特点

3. **personality**: 性格关键词（3-5个）

4. **scenario**: 相遇场景（邻居/同事/健身房/偶遇）

5. **first_mes**: 第一句话（要符合人设）

### 可选字段

- **mes_example**: 对话示例
- **character_book**: 世界书（补充背景信息）
- **alternate_greetings**: 多个开场白

---

## ⚠️ 注意事项

1. **肖像权**: 使用公开的宣传照片
2. **内容分级**: 可以设置不同尺度的对话内容
3. **场景设定**: 建议多样化（避免重复）
4. **个性差异**: 每个角色要有独特性格
