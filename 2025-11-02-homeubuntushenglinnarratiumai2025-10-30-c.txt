  📚 系统如何推进故事

  系统通过 9个处理节点 的流水线来推进故事：

  用户输入
    → 加载系统预设
    → 获取对话历史
    → 🌟世界书注入知识🌟
    → LLM生成回复
    → 输出结果

  核心机制：世界书触发

  关键词匹配：当你说"魔法学院"时，系统会自动找到相关世界书条目并注入到prompt中，让AI知道这个地点的
  详细信息。

  举例：
  - 你说："我想去魔法学院"
  - 系统检测到关键词"魔法学院"
  - 自动注入世界书内容："魔法学院位于山顶，有三座高塔..."
  - AI回复时就能准确描述学院的样子

  🎭 角色卡和世界书的作用

  角色卡 = 定义"演员"

  - personality：控制说话语气（如"活泼开朗"）
  - scenario：设定剧情背景（如"魔法学院导游"）
  - first_mes：开场白，设定初始氛围

  世界书 = 定义"舞台"

  - constant: true 的条目：核心世界观，AI始终知道
  - keys 触发 的条目：按需提供知识，提到才注入
  - position 分层：控制信息优先级（0-4）

  🎨 如何创建新故事

  快速方法（推荐）

  1. 准备角色卡文件：
    - 使用在线工具创建：https://character-card-creator.vercel.app/
    - 或下载现成的：https://www.chub.ai/
  2. 导入到应用：
    - 访问 http://localhost:3000/character-cards
    - 点击"导入角色"
    - 上传PNG文件
  3. 测试对话：
    - 进入聊天界面
    - 发送不同消息测试世界书触发

  手动创建（完全自定义）

  我在文档中提供了完整的模板和示例：

  // 角色设定模板

  // 一键迁移脚本
  (async () => {
    console.log('🚀 开始迁移角色卡...');

    // 1. 读取浏览器数据
    const dbRequest = indexedDB.open('CharacterAppDB', 10);

    dbRequest.onsuccess = async (event) => {
      const db = event.target.result;

      // 获取角色卡列表
      const tx1 = db.transaction(['characters_record'], 'readonly');
      const store1 = tx1.objectStore('characters_record');
      const getRequest = store1.get('data');

      getRequest.onsuccess = async () => {
        const characters = getRequest.result || [];
        console.log(`📱 浏览器中有 ${characters.length} 个角色卡`);

        if (characters.length === 0) {
          console.log('⚠️ 没有需要迁移的角色卡');
          return;
        }

        let success = 0;
        let failed = 0;

        // 2. 逐个迁移
        for (const char of characters) {
          const name = char.data?.name || char.id;
          console.log(`📤 正在迁移: ${name}`);

          try {
            // 获取图片
            let imageData = null;
            if (char.imagePath) {
              const tx2 = db.transaction(['character_images'], 'readonly');
              const store2 = tx2.objectStore('character_images');
              const imgRequest = store2.get(char.imagePath);

              const blob = await new Promise((resolve) => {
                imgRequest.onsuccess = () => resolve(imgRequest.result);
              });

              if (blob) {
                imageData = await new Promise((resolve) => {
                  const reader = new FileReader();
                  reader.onloadend = () => resolve(reader.result);
                  reader.readAsDataURL(blob);
                });
              }
            }

            // 上传到服务器
            const response = await fetch('/api/characters', {
              method: 'POST',
              headers: { 'Content-Type': 'application/json' },
              body: JSON.stringify({
                id: char.id,
                data: char.data,
                imageData: imageData
              })
            });

            if (response.ok) {
              console.log(`✅ 成功: ${name}`);
              success++;
            } else {
              const error = await response.json();
              console.error(`❌ 失败: ${name} - ${error.error}`);
              failed++;
            }
          } catch (error) {
            console.error(`❌ 失败: ${name} - ${error.message}`);
            failed++;
          }
        }

        console.log(`\n🎉 迁移完成！`);
        console.log(`✅ 成功: ${success} 个`);
        console.log(`❌ 失败: ${failed} 个`);
      };
    };

    dbRequest.onerror = () => {
      console.error('❌ 无法打开 IndexedDB');
    };
  })();
