  - 图片生成比 TTS 更耗时（可能 10-30 秒）
  - 需要良好的 UX 设计：
    - 加载动画
    - 进度提示
    - 可取消操作

  4.3 API 成本
  - 每次生成场景图：LLM 调用（提示词生成）+ 图像生成 API
  - 建议：
    - 添加开关，允许用户禁用自动生成
    - 或改为手动触发（点击按钮生成）

  4.4 图片存储
  - 生成的图片 URL 如何管理？
  - 与哪条消息关联？
  - 如何缓存避免重复生成？
  - 建议：

    content: string;

      url: string;
      prompt: string;      // 记录生成时的提示词

    };
  }

  4.5 人像来源
  - 角色的参考人像从哪里来？
  - 用户上传？AI 生成？预设库？
  - 建议：

    - 后期：集成 AI 人像生成功能

  4.6 工作流 ID 硬编码
